# Support

## How to get help

HA-DocGen is a documentation and analysis tool for Home Assistant
configuration repositories.

Before opening an issue:

1. Read the project documentation in [`docs/`](docs/README.md).
2. Check existing [GitHub Issues](https://github.com/Mazzo26/HA-DocGen/issues).
3. Confirm you are using a supported Python version (`>=3.14`).

## Bug reports

Use the **Bug report** issue form for defects, crashes, incorrect analysis,
or incorrect generated output.

Include:

- HA-DocGen version (`ha-docgen --version` or `python -m ha_docgen --version`)
- Python version
- Operating system
- Steps to reproduce
- Expected and actual behaviour

Do not attach private Home Assistant configuration that contains secrets.

## Feature requests

Use the **Feature request** issue form for proposed enhancements.

## Security vulnerabilities

Do not open a public issue for security-sensitive reports.
Follow [SECURITY.md](SECURITY.md).
